# CLAUDE.md

## Design

All UI and interaction design in this project — in Figma and in code — follows
`docs/design-principles.md`. Read it before designing, reviewing or changing any screen,
and justify design choices through it. If a request conflicts with those principles, say so
briefly and propose an alternative.

The design rulebook is `docs/design.md`. It overrides ad-hoc choices: do not add colours, sizes or spacing that are not tokens without asking.
