# CLAUDE.md

## Design

All UI and interaction design in this project, in Figma and in code, follows `docs/design.md`. It holds the design principles, tokens,
component and layout rules. Read it before designing, reviewing or changing any screen. If a request conflicts with it, say so briefly and
propose an alternative. Do not add colours, sizes or spacing that are not tokens without asking.

Always check light and dark mode and all three club themes. Explain why a design choice was made and ask before deviating.

## Project log

Record progress, decisions with trade-offs, problems and results in `docs/project-log.md` (portfolio case file). Update it after each session.
